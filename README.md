# 🍱 Blessing Boxes – Food Donation Platform

A full-stack Django web application designed to reduce food waste by connecting **food donors** (restaurants, individuals) with **NGOs** for efficient redistribution.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup)
- 🍽️ Food Donation Management (Create, Edit, Delete)
- 🏢 NGO Dashboard for managing donations
- 📧 Email Notifications to NGOs on new donations
- 📍 Location-based donation tracking (Latitude & Longitude)
- 👥 Role-Based Access Control (Donor / NGO / Volunteer)
- 📱 Responsive UI for better user experience

---

## 🛠️ Tech Stack

- **Backend:** Django, Python  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** SQLite  
- **Other:** Django ORM, Signals, Email Integration
